# 口语化改写规则

口播是「说」出来的，不是「读」出来的。改写只动句式与用词，不动事实。下面规则按优先级排。

## 一、长句拆短

书面语爱用长从句，口语要一句一个信息点。

- 书面：「由于项目临近上线且测试环境数据尚未同步完成，我们不得不临时推迟了发布窗口。」
- 口语：「项目要上线了，但测试环境的数据还没同步过来。/ 没办法，发布只能往后推。」

规则：

- 一个句子尽量不超过 20 字；超了就断。
- 多层因果拆成「因为 / 所以 / 结果呢」分两句说。
- 拆完用 `/` 标停顿，仍属同一语义单元。

## 二、书面词换口语词

| 书面 | 口语 |
|---|---|
| 因此、故而 | 所以、结果 |
| 然而 | 但是、可 |
| 诸多 | 很多 |
| 获悉 | 听说、知道 |
| 予以处理 | 去弄、去管 |
| 彼时 | 那时候 |
| 进行 | 直接删或换动词 |
| 便于 | 好让、省得 |

规则：能用一个动词就说一个动词，少用「进行 / 予以 / 通过……方式」这类名词化套话。

## 三、加语气衔接

让讲述有呼吸感，自然过渡。

- 常用：「说白了」「结果呢」「你猜怎么着」「后来」「说起来」「反正」
- 衔接词只加在句间，不塞进事实句里改原意。

## 四、停顿与重音标注规范

标注是给「讲的人」看的，不改变文字本身。

- 停顿 `/`：一句话说完换气、或强调前后对比处。例：「我等了三天 / 他一句话没回。」
- 重音 `**加粗**`：一句话里最该被听见的词，通常是对比点、数字、反转词。例：「他说 **还行**，转头就换了人。」
- 长句换气 `‖`：一口气读不下来的长句，在换气点标 `‖`。例：「那天从早会一直吵到下班 ‖ 没人记得最初要聊什么。」

规则：

- 重音一屏（一句）不超过 1~2 个，标太多等于没标。
- 停顿不要太密，否则讲起来像念经；一般每 2~3 句一个 `/` 足够。
- 标注只在讲稿副本上体现，交付给用户时可附一份「纯文字版」便于他直接读。

## 五、事实红线（不可逾越）

以下任何一项都**不得因口语化而改动**：

- 时间（「三天」不能顺手变「一周」）
- 数字（金额、次数、人数、比例）
- 对话引述（他人原话不能转述成别的意思）
- 具体动作与结果（谁做了什么、导致什么）

若用户原话本身模糊（如「等了好久」），保留模糊，不替他精确化；可在事实核对表里标「『好久』请确认约多久」。
